wrong_sql = "SELECT id FROM loans WHERE returned_on = NULL ORDER BY id;"
example_sql = "SELECT id FROM loans WHERE returned_on IS NULL ORDER BY id;"

普通的等值比较遇到 NULL 会得到未知值。WHERE 只保留条件为真的行。需要匹配空值时，使用 IS NULL。需要排除空值时，使用 IS NOT NULL。
