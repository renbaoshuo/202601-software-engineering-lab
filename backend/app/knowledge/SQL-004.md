title = "GROUP BY 与未分组的结果列"
keywords = "group by aggregate bare column maximum 分组 聚合 裸列 列"
source = "https://www.sqlite.org/lang_select.html#bareagg"
applicable = "每个分组输出一个结果时，需说明每个输出列的来源。"
dataset_id = "retail"
wrong_sql = "SELECT city, name, COUNT(*) FROM customers GROUP BY city ORDER BY city;"
example_sql = "SELECT city, COUNT(*) AS customer_count FROM customers GROUP BY city ORDER BY city;"
+++
SQLite 允许结果包含既未参与分组也未聚合的列，该列可能来自组内某一行。定义汇总输出时，应明确列参与分组、参与聚合或如何确定具体行。
