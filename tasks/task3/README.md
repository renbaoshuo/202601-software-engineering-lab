# 团队第三次作业—alpha冲刺

博客截止时间：2026.11.21 23:59

## 介绍

alpha冲刺主要是让各个团队对之前展示给大家的项目和工作进行**总结与思考**，同时，给出对该项目的改进思路，同时展现出团队里的团结与合作，希望能够让大家在冲刺阶段进一步体会到团队合作的激情与快乐。

注：每次冲刺需要十分钟左右站立会议，控制好时间，不要在此会议上讨论细节问题。  
Alpha 冲刺应该至少持续 14 天，作业需要1篇冲刺总结来体现。

全员到场，缺席需说明原因。

## 需求

### 1\. 1篇冲刺计划

1.  对于团队之前的工作进行**总结与思考**，并给出可以改进的思路和方案
2.  以**表格的形式**呈现每名成员的**实际承担的工作和工作量**

### 2\. 1篇冲刺总结

由队长将该篇随笔提交（本次作业只须提交该篇博客），名称格式为：团队名称-冲刺总结，具体要求如下：

1.  描述是否都实现了冲刺计划中对项目的改进？项目的亮点有哪些？项目目前还有哪些不足？
2.  附带冲刺计划的链接
3.  每位成员的过程体会
4.  说明每个成员完成了哪些内容及在整个阶段的工作量比例
5.  给出团队项目的Github仓库链接（你们的大作业github仓库链接）

### 3\. 1个vlog（名字自拟）

1.  简单叙述一下你们的冲刺计划
2.  展示每天冲刺日志的重要内容，并展示开发过程中与队友的交流过程
3.  视频内容要求采用剪辑，将每天拍摄的视频进行整合
4.  视频要求3-5分钟
5.  以上为基本要求，然后发挥你们的激情和想象力，让这个vlog更加精彩吧

### 博客分数【100'】占比：

- 1篇冲刺计划【15'】
- 1个vlog【25'】
- 1篇冲刺总结【60'】

### github仓库

- 将此次作业的**PPT**放到第一次团队作业所要求创建的大作业github仓库中
- 每有一个较大的进展，请发布一个对应的版本release，版本号应遵守行业的命名规范

### 答辩PPT

- 项目的成员分工和预期计划
- 项目的实际进度曲线、燃尽图
- 遇到哪些问题，以及是怎么解决的
- 项目的实际架构：前后端开发框架，使用到的技术，部署的流程等
- 描述项目的测试工作安排、测试工具选择和运用、项目测试评述
- 成员的过程体会

### 答辩流程

1.  PPT演讲
2.  作品展示，请演示的同学携带电脑，电脑需要预先调试好项目，确定可以运行，如果需要使用手机或其他设备投屏到电脑，请预先准备预先调试好
3.  vlog演示
4.  每组将严格限制演示时长（15分钟内，超过时长会被扣分）：PPT演示+作品演示（10分钟）、vlog展示（5分钟）

### 现场要求【100'】：

打分项：

- PPT质量（20′）
- 演讲（10′）
- 项目功能完成度（35′）
- UI设计和交互体验（25′）
- vlog（10'）
