### 项目规划

团队项目 **QueryPilot** 选择 SQL 学习与查询诊断领域，主要面向正在学习数据库课程的大学生和需要调试基础 SQL 的初级开发者。我们希望帮助用户理解报错原因，发现查询结果与目标之间的偏差，并通过实际运行验证修改效果。产品采用 Web 应用形式，用户通过浏览器即可完成查询编写、运行和诊断。

团队访谈了几位目标用户群体的成员，收集他们近期遇到的 SQL 问题，了解原有解决办法，以及使用教材、搜索引擎或通用 AI 后仍未解决的困难。调研重点关注用户是否理解修改建议、如何判断查询结果正确，以及是否需要保存和恢复调试过程，并据此调整了我们预期实现的功能范围。

软件支持配置表结构、编辑 SQL 和运行查询。用户描述查询目标后，可以请求 Agent 诊断，查看解释、执行证据和修改建议，再自行修改并重新运行。工作台还将提供个人模型配置、本地会话历史和历史导入导出，通过工具轨迹与流式回答展示诊断进展。

智能体定制围绕 SQLTutorAgent 展开。团队计划整理 15–20 个经过核验的知识条目，覆盖 NULL、连接、聚合、子查询等规则和典型错误，保留来源及可复现示例，并采用 BM25 检索相关内容。Agent 将按任务需要调用 SQL 静态分析、表结构查看、沙箱执行和知识检索四类工具，结合真实结果解释问题。例如统计全部部门人数时，可以通过执行结果发现空部门被错误计数，再结合聚合规则说明原因，引导用户修改后验证。

评测计划准备约 30 个案例，划分开发集和独立留出集，对比通用模型、加入解析与执行反馈的模型，以及完整领域 Agent。团队将检查诊断解释、建议可执行性和知识引用是否可靠，保留失败案例与实际输出，用可复现的结果说明领域定制带来的变化。

## 需求分析文档

我们编写的《QueryPilot 软件需求规格说明书》定义了一款面向数据库课程学生和初级开发者的 SQL 学习与诊断 Web 应用。用户可在浏览器中选择内置数据集、查看表结构、编写并运行 SQLite 只读查询；遇到报错或结果不符预期时，调用后端由大模型驱动的 SQLTutorAgent，结合静态分析、沙箱执行结果和领域知识库给出带证据的诊断解释，再自行修改并验证。设计上强调隐私与本地优先：会话和历史保存在浏览器本地，模型配置由用户个人提供且仅在单次请求中使用；诊断结论必须对应真实工具调用记录，执行仅限内置数据集上的只读查询。

全文共四章：第 1 章引言说明目的、范围和术语；第 2 章总体描述产品架构、功能、用户与约束；第 3 章为主体，规定界面、五个应用 API、SQL 编辑运行、Agent 诊断、知识检索、模型配置、会话历史、工具轨迹、流式回答等具体需求，以及性能、技术栈、安全和离线评测方案；第 4 章给出六个维度的验收操作。若关注产品功能可读第 2 章与 3.2 节，关注接口实现看 3.1 与 3.4 节，验收则对照第 4 章。
